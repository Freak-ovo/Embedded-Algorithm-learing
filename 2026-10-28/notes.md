## 程序一：数组逆序

### 输入

`{1, 2, 3, 4, 5}`

### 输出

`{5, 4, 3, 2, 1}`

### 处理思路

1. 左指针指向第一个元素；
2. 右指针指向最后一个元素；
3. 交换左右指针指向的元素；
4. 左指针向右移动；
5. 右指针向左移动；
6. 当左指针不再小于右指针时停止。

### 关键状态

- `left`：左侧待处理元素下标；
- `right`：右侧待处理元素下标；
- `temp`：交换时临时保存元素。

### 边界情况

- 空数组；
- 单元素数组；
- 两个元素；
- 奇数长度数组；
- 偶数长度数组；
- 全部元素相同。

## 程序二：删除指定值

### 输入

- 数组：`{3, 2, 2, 3, 4, 2}`
- 删除目标：`2`

### 输出

- 有效数据：`{3, 3, 4}`
- 新有效长度：`3`

### 处理思路

使用读指针和写指针：

1. `read` 遍历原数组；
2. `write` 表示下一个保留元素的写入位置；
3. 如果当前元素不等于目标值，将其写入 `numbers[write]`；
4. 写入后将 `write` 加1；
5. 如果当前元素等于目标值，跳过；
6. 最终 `write` 就是新的有效长度。

### 关键状态

- `read`：当前读取位置；
- `write`：下一个保留元素的写入位置；
- `target`：需要删除的值。

### 注意

数组的底层容量没有改变，只是有效长度发生了变化。
处理完成后，只能把前 `new_length` 个元素视为有效数据。

## 程序三：移动零

### 输入

`{0, 1, 0, 3, 12}`

### 输出

`{1, 3, 12, 0, 0}`

### 要求

- 所有0移动到数组末尾；
- 非零元素的相对顺序不变；
- 原地修改数组。

### 处理思路

第一阶段：

1. 使用 `read` 遍历数组；
2. 使用 `write` 表示下一个非零元素的写入位置；
3. 遇到非零元素时，将其写入 `numbers[write]`；
4. 将 `write` 加1。

第二阶段：

1. 从 `write` 开始；
2. 将剩余数组位置全部设置为0。

### 关键状态

- `read`：当前读取位置；
- `write`：下一个非零元素的写入位置。
