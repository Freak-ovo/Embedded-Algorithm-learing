## 程序二：验证下标访问和指针访问

### 核心关系

`numbers[i]` 与 `*(numbers + i)` 都用于访问数组第 `i` 个元素。

### 初步理解

- `numbers`：第一个元素的位置；
- `numbers + i`：第 `i` 个元素的位置；
- `*(numbers + i)`：读取第 `i` 个元素的值。

### 需要验证

对于同一个下标：

- `numbers[i]` 的值；
- `*(numbers + i)` 的值；
- `&numbers[i]`；
- `numbers + i`；

对应结果是否相同。

## 程序三：顺序查找

### 输入

- 数组：`{5, 8, 12, 3, 9}`
- 目标值：`12`

### 输出

目标值所在下标：`2`

### 函数接口

`int find_value(const int numbers[], int length, int target);`

### 处理步骤

1. 从下标0开始遍历数组；
2. 比较当前元素和目标值；
3. 如果相等，返回当前下标；
4. 如果遍历结束还没有找到，返回 `-1`。

### 返回值约定

- 大于等于0：找到了，返回值为目标下标；
- `-1`：没有找到。

### 边界情况

- 目标在第一个位置；
- 目标在最后一个位置；
- 目标不存在；
- 数组中存在重复目标；
- 数组只有一个元素；
- 数组长度为0。
