# Embedded Algorithm Learning

面向嵌入式 Linux 软件开发的数据结构与算法学习仓库。

## 学习目标

1. 夯实 C/C++ 编程基础；
2. 掌握常用数据结构与基础算法；
3. 建立规范的代码编写、编译、调试和测试习惯；
4. 将数据结构与嵌入式 Linux 场景结合；
5. 为嵌入式 Linux 岗位的笔试和面试做准备。

## 学习方式

每个知识点按照以下流程学习：

1. 理解问题和应用场景；
2. 手动画出数据结构或执行流程；
3. 先写伪代码；
4. 独立编写程序；
5. 编译并消除警告；
6. 测试普通输入和边界输入；
7. 使用 GDB 或打印信息调试；
8. 分析时间和空间复杂度；
9. 使用 Markdown 记录总结；
10. 提交到 Git。
